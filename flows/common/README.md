# common/ — shared subgraph library

Master copies of the subgraphs the project flows share. **Each file is one component**,
shaped like a frontend subgraph blueprint: the root graph holds one instance node and
`definitions.subgraphs` holds its one definition. Open a file to see or edit the
component; the same file can be published unchanged under userdata `subgraphs/` to
appear in the node library under *Subgraph Blueprints*.

- Remote (source of truth): `workflows/common/*.json`
- Local mirror: `flows/common/*.json`
- Generated by `.claude/skills/comfyui-flow-authoring/scripts/common_subgraphs.py`
  from real nodes in the flows listed under *Source*. Widget values, node sizes and
  properties are copied, not retyped.

## How the library stays in sync

ComfyUI has **no cross-file subgraph reference**. Every flow embeds its own copy of
each definition in `definitions.subgraphs`, matched to its instances by UUID. The
UUIDs here are fixed (uuid5 of the slug), so a flow that embeds `qwen-panel` always
carries `1169d8ab-…`. To change a component: edit the master here, then re-sync every
flow that embeds that UUID. Editing an instance inside one flow changes only that flow.

## Rules every component follows

- **Explicit inputs, no hidden Get nodes.** Everything a component reads comes in
  through a socket (model, clip, vae, card, upscale model…). v3's old panel read
  `Get_CARD`/`Get_CLIP` from inside, which only worked in flows with those exact
  Set names.
- **On/off lives on the instance.** Inner nodes are always `mode 0`. Bypass or mute
  the *instance* (Ctrl-B / Ctrl-M, or a group bypasser); the converter removes it
  with type-matched pass-through before expansion. A bypassed *inner* node can't be
  expanded at all.
- **Optional stages stay outside.** Speed LoRAs, TorchCompile and the LoRA slot are
  never inside a loader component, so they remain bypassable.
- **Seeds stay inside** (fixed, 424242 unless noted). `steps`/`cfg` are promoted.
- Model-rule validations only scan the root graph, so a decoder inside a component
  isn't checked by `qwen-image-channels`. QC the output.

## Defaults and usage guidelines

- **qwen-panel**: 768 native (`resolution`), 30 steps, cfg 4.5, euler/simple, seed 424242
  fixed, denoise 1. Don't use cfg 1 with the UC GGUF (noise). Panels with reference
  images must take the **uncompiled** model (ROCm recompile → sticky
  `hipErrorIllegalAddress`). The latent comes from the encoder at `resolution`.
- **esrgan-upscale-rescale**: `scale_by 0.5` = net x2 (768 → 1536). Put the whole
  instance in the bypassable 06 group so bypass yields native size, not a resample.
- **esrgan-x4**: full x4, no resample (v3's deliverable).
- **sheet-2x2**: panels 1|2 over 3|4, spacing 0 (grid/alpha convention forbids solid
  dividers). Depends on all four inputs, so bypass it together with any panel you bypass.
- **wan22-two-stage-sampler**: lightx2v on → 4 steps / cfg 1 / split 2; off →
  20 / 3.5 / 10. High stage adds noise and returns leftover noise; low stage finishes.
- **rife-x2-video-save**: x2 frames; set `fps` to twice the raw rate (16 → 32).
  Bypass the instance to skip interpolation.
- **faceid-sdxl-setup / face-detail-rgba**: SDXL photoreal; FaceDetailer ships with
  guide 512 / max 768 / tiled enc+dec, because tiny faces at 512 crashed the GPU
  (see skill traps). Free VRAM between the Qwen and SDXL passes (v3 uses `VRAM_Debug`
  glue outside the components).
